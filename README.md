# Dental Santé — Home institucional

Home estática pronta para Vercel. Não há build step nem dependências de runtime.

## Estrutura

- `index.html` — estrutura semântica e conteúdo da página.
- `styles.css` — tokens visuais, layout responsivo e estados.
- `script.js` — menu mobile, scroll progressivo, modais de tratamentos/equipe e reveals.

## Publicar na Vercel

1. Aponte a Vercel para esta pasta (`dental-sante-home`).
2. Selecione o preset **Other** ou deixe o framework sem configuração.
3. Use a raiz do projeto como `/dental-sante-home` caso o repositório contenha outros projetos.

Os links de agendamento, telefone, mapa, Instagram, YouTube e as imagens atuais apontam para os canais/ativos oficiais da Dental Santé. Para produção, vale baixar esses ativos para uma pasta `assets/` própria antes do lançamento, evitando dependência de URLs externas.
